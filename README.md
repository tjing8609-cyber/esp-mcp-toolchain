# 电子钢琴 (Digital Piano) v3

## 文件说明

| 文件 | 说明 |
|------|------|
| `main.py` | 主程序，上传到 ESP32 根目录自动运行 |
| `config.py` | GPIO 映射和音符频率表，按实际接线修改 |
| `README.md` | 本说明文件 |

## 硬件接线

所有琴键一端接 **GND**，另一端串联 LED 后接对应 GPIO。
按键与 LED 串联 → 按下时 LED 自动亮，无需软件控制。

```
   GPIOx ───┬─── 按键 ─── LED ─── GND
            │
    内部上拉电阻 (~45kΩ)
            │
          3.3V
```

### GPIO 对照表

| 功能 | GPIO | 说明 |
|------|------|------|
| 蜂鸣器 (无源) | **GPIO2** | PWM 驱动 |
| 琴键 C4 + LED | **GPIO5** | 按键→LED→GND 串联 |
| 琴键 D4 + LED | **GPIO12** | 按键→LED→GND 串联 |
| 琴键 E4 + LED | **GPIO14** | 按键→LED→GND 串联 |
| 琴键 F4 + LED | **GPIO19** | 按键→LED→GND 串联 |
| 琴键 G4 + LED | **GPIO21** | 按键→LED→GND 串联 |
| 琴键 A4 + LED | **GPIO22** | 按键→LED→GND 串联 |
| 琴键 B4 + LED | **GPIO23** | 按键→LED→GND 串联 |
| 功能键 KEY1 | **GPIO34** | 录音（仅输入，内部上拉） |
| 功能键 KEY2 | **GPIO35** | 播放小星星（仅输入，内部上拉） |
| 状态 LED 绿 | **GPIO32** | 板载指示灯 |
| 状态 LED 红 | **GPIO33** | 板载指示灯 |

## 操作说明

| 操作 | 效果 |
|------|------|
| 按琴键 | 发声，按住持续、松开停音 |
| 按住 KEY1 不放 + 按琴键 | 高/低八度 |
| 按 **KEY2** | 自动播放「小星星」|
| 播放中按任意琴键 | 停止播放，回钢琴模式 |
| 按 **KEY1** | 开始录音 |
| 录音中弹琴键 | 记录音符 |
| 录音中按 **KEY1** | 停止录音，自动回放 |

## 使用方法

1. ESP32 刷入 MicroPython 固件（推荐 v1.23+）
2. 用 Thonny / mpremote 上传以下文件到开发板根目录：
   - `config.py`
   - `main.py`
3. 复位开发板，程序自动运行

## 自定义 GPIO

如果接线不同，打开 `config.py` 修改对应 GPIO 编号即可。
`main.py` 不需要改动，所有 IO 都通过 `config.py` 导入。
